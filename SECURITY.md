# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this WiseCP VirtFusion module, please **do not** open a public GitHub issue with exploit details.

Instead, report it privately via GitHub's **Private Vulnerability Reporting** feature on this repository (or contact the maintainer directly) with:

- A clear description of the vulnerability and its potential impact
- Steps to reproduce or a minimal proof of concept
- Any suggested fix, if available

We will acknowledge your report as promptly as possible and coordinate a fix before public disclosure.
